## 7. Proposed fix for D1 (needs approval: touches 3 crates)

Defect: `CallSite` keeps only the last path segment. `HashMap::new()` is stored as callee `new` with form `Path`. `pick()` then accepts any non-class symbol named `new`.

Correction:

1. Add `qualifier: Option<String>` to `CallSite`. It holds the segment before the name: `HashMap` in `HashMap::new()`.
2. Store it in a new `calls.qualifier` column and bump `SCHEMA_VERSION` to 4, so old indexes are rebuilt.
3. In `pick()`, for the `Path` form:
   - `Self`, `self`, `crate` or `super` → current behaviour.
   - Type-like (upper case) → only a method whose owner is that type.
   - Module-like (lower case) → only a function whose file stem or crate directory matches.
   - Anything else stays `Unresolved`, with a note.

Regression risks: some links that are correct today get lost, for example through a `use` alias or a re-exported module path. They become `Unresolved`, which is the safe direction. The JSON output gains a field. Tests: the parser test for the qualifier, a malformed Rust input, and an index test asserting that `Vec::new()` does not link to a project `new`.

## 8. Usability: the five most important problems

Judged from three users: a beginner, a developer looking for a function, and a senior engineer reviewing an AI change.

1. **U1: Silent false confidence.** Empty callers for React components (D4), wrong `Inferred` links for Rust (D1), and "No rule flagged a risk" on a broken rename (D5). Each looks like a fact. This matters most for a reviewer of AI-generated code.
2. **U2: No language coverage summary.** "736 unsupported" should say "736 files not analysed: Dart (394), images, …". A Flutter user is not told that Tracemark cannot read the app.
3. **U3: No project memory.** The desktop forgets the last project. Every launch starts at the folder picker.
4. **U4: Locations are cut off and not clickable.** In the symbol list the path is truncated before the line number (`crates/tracemark-index/src/lib.rs:3…`). Nothing opens the file in an editor.
5. **U5: Output does not scale.** The HTML report is 35 MB for a medium project. The desktop caps lists at 500 with "Type to narrow". A per-file or per-symbol view is needed.

What helps users answer the core questions:

- Where is it defined: works.
- What does it connect to, and what calls it: works for plain calls. Wrong or missing for Rust paths, JSX and member calls.
- What changed and what may be affected: works for symbols. Missing for imports.
- What is verified versus inferred: the evidence tags work and are visible everywhere. Add a one-line legend to empty results ("0 linked callers: JSX, member and dynamic calls are not seen").
