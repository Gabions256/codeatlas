## C. Code signing

Current state: the Windows installer and `tracemark.exe` are **not Authenticode-signed** (`Get-AuthenticodeSignature` → `NotSigned`). The macOS `.dmg` is not notarized. Every artifact has a verified GitHub build-provenance attestation. That proves where an artifact came from, but Windows and macOS do not use it to decide whether to warn users.

| Option | Platform | Cost (check before buying) | Requirements and trade-offs |
| --- | --- | --- | --- |
| Azure Artifact Signing (formerly Trusted Signing) | Windows | Basic plan about **US$9.99/month** for 5,000 signatures. Premium about US$99.99/month. | Microsoft-managed keys, works from GitHub Actions, short-lived certificates. Reported as generally available in the USA, Canada and Europe. **Eligibility for individuals and identity checks must be confirmed** with Microsoft for the owner's country. |
| SignPath Foundation | Windows | **Free** for qualifying open-source projects | OSI licence (Apache-2.0 qualifies), public repository, MFA for all team members, and a published code-signing policy with defined roles. **The certificate names SignPath Foundation as publisher, and an attribution line is required.** That conflicts with the owner's wish that only their name appears, so the owner must decide. |
| Commercial OV certificate (Sectigo, DigiCert, SSL.com, …) | Windows | Typically a few hundred US$ a year (not verified for 2026) | Since 2023 the private key must live in a hardware token or a cloud HSM, which complicates CI signing. SmartScreen reputation still builds up over time. |
| EV certificate | Windows | Higher than OV (not verified) | No longer gives instant SmartScreen reputation. Same HSM requirement. Not recommended for this project. |
| Apple Developer Program | macOS | **US$99/year** (Apple's long-standing price; confirm) | Developer ID Application certificate plus notarization with `notarytool`. Can run in CI with an App Store Connect API key. Needs the owner's Apple ID and enrolment as an individual or an organisation. |
| Linux | Linux | Free | Optional: GPG-sign the checksum files. The provenance attestations already cover integrity. |

Recommendation: the owner chooses between Azure Artifact Signing (cheap, the owner's name as publisher, if eligible) and SignPath (free, SignPath Foundation as publisher). Then apply for Apple Developer once macOS users matter. **Blocked by user action**: every option needs the owner's identity verification, and all but SignPath need payment.

## D. Trademark: preliminary name-clearance checklist

This is a research checklist, not legal advice. **Nothing here establishes that "Tracemark" is available.** A qualified trademark professional must clear the name before any registration or major marketing spend.

1. Search the registers in the classes for software and SaaS: Nice classes **9** (downloadable software) and **42** (software services).
   - USPTO trademark search (US).
   - EUIPO eSearch plus (EU).
   - WIPO Global Brand Database (international filings).
   - The national office of the owner's home market, and every country where the product is mainly marketed.
2. Search exact and similar marks: "Tracemark", "Trace Mark", "TraceMark", and phonetic look-alikes in software ("Tracemarks", "TrackMark").
3. Check common-law use: GitHub, crates.io, npm, PyPI, the VS Code Marketplace, JetBrains Marketplace, the app stores, Product Hunt, and a general web search for software products using the name.
4. Check domains: `tracemark.dev`, `.io`, `.com`, `.app`.
5. Check social handles and the GitHub organisation name.
6. Record the date and evidence of first public use: the first release `v0.2.0` under the new name, 2026-11-13.
7. Ask a professional for a clearance opinion, then decide on a filing route (national, EUTM, or Madrid Protocol) and its cost.
8. Until then, use the name with no ® symbol. "™" may be used to claim an unregistered mark where local law allows.
